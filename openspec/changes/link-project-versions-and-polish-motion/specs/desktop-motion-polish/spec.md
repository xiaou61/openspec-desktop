## Purpose

为高频使用的桌面管理工作区建立一致、快速且有空间连续性的交互反馈，在不牺牲性能、可访问性与信息密度的前提下提升界面质感和状态可理解性。

## ADDED Requirements

### Requirement: 动效必须服务于反馈与状态理解
系统 MUST 只为按压反馈、浮层空间来源、选择状态、内容进入退出和进度变化提供动效；高频操作不得因纯装饰动画延迟响应，循环动效 MUST 仅用于确有进行中状态的指示。

#### Scenario: 用户重复切换详情标签
- **WHEN** 用户连续切换文档、任务、活动和修订标签
- **THEN** 每次选择 MUST 立即生效且内容 MUST 在 300 毫秒内稳定
- **THEN** 动效 MUST NOT 阻止下一次点击、键盘操作或内容滚动

#### Scenario: 使用键盘触发高频操作
- **WHEN** 用户通过键盘切换标签、关闭浮层或执行命令
- **THEN** 系统 MUST NOT 增加等待交互完成的装饰性位移动画

### Requirement: 可按压控件提供即时物理反馈
按钮、图标按钮、项目行、Change 行和分段控件 MUST 在指针按下时提供轻微且稳定的缩放或明暗反馈，并在释放或取消时迅速恢复；反馈不得改变布局尺寸。

#### Scenario: 指针按下按钮
- **WHEN** 用户按下一个可用按钮
- **THEN** 按压反馈 MUST 在 100 毫秒内开始且视觉缩放 MUST 保持克制

#### Scenario: 控件处于禁用或加载状态
- **WHEN** 用户尝试操作禁用控件或正在提交的命令
- **THEN** 控件 MUST 保持稳定状态且不得播放暗示操作成功的反馈

#### Scenario: 触摸设备产生模拟悬停
- **WHEN** 环境不支持精确悬停指针
- **THEN** 系统 MUST NOT 保留可能误导用户的悬停位移或缩放状态

### Requirement: 浮层动效保持空间连续性
下拉菜单和提示层 MUST 从触发控件方向进入并回到同一方向退出；居中对话框 MUST 从视口中心进入退出；遮罩与内容 MUST 协调过渡且焦点管理不得受动画影响。

#### Scenario: 打开版本菜单
- **WHEN** 用户激活项目标题区的版本控件
- **THEN** 菜单 MUST 从触发点附近以透明度和轻微缩放进入
- **THEN** 菜单内容 MUST 在 250 毫秒内可完整交互

#### Scenario: 打开项目设置对话框
- **WHEN** 用户打开居中项目设置
- **THEN** 对话框 MUST 以中心为变换原点且遮罩同步淡入
- **THEN** 焦点 MUST 立即进入对话框并在关闭后返回触发控件

#### Scenario: 快速反向操作
- **WHEN** 浮层进入尚未完成时用户立即关闭它
- **THEN** 过渡 MUST 从当前视觉状态平滑反向而不是重新跳到起点

### Requirement: 选择与内容变化保持连贯
标签指示器、分段控件、版本筛选、列表选择和进度变化 MUST 在状态切换时保持位置关系清晰；动画期间文本、图标和列表轨道 MUST NOT 跳动或重排。

#### Scenario: 切换详情标签
- **WHEN** 用户选择另一个详情标签
- **THEN** 活动指示器 MUST 平滑移动或显隐到新标签
- **THEN** 新内容 MUST 通过短促透明度过渡进入且容器宽高约束 MUST 保持稳定

#### Scenario: 任务进度更新
- **WHEN** 已完成任务数发生变化
- **THEN** 进度条 MUST 从原比例平滑到新比例
- **THEN** 更新 MUST NOT 触发周围文本和卡片重新测量造成的可见跳动

#### Scenario: 实时列表新增活动
- **WHEN** 文件监听产生一条新活动
- **THEN** 新行 MAY 使用一次短促进入反馈
- **THEN** 既有行 MUST 保持可阅读位置且用户当前滚动不得被强制重置

### Requirement: 玻璃材质具有清晰层级和实色降级
半透明与背景模糊 MUST 只用于导航、工具栏、浮层和对话框等需要表达层级的表面；正文与密集列表 MUST 保持高可读实色基底，所有玻璃表面 MUST 有细边界与足够对比。

#### Scenario: 平台支持背景模糊
- **WHEN** 运行环境支持背景模糊且用户未要求减少透明度
- **THEN** 合适的高层表面 MUST 使用克制的透明度、模糊、细高光和轻阴影表达层级

#### Scenario: 平台不支持背景模糊
- **WHEN** 运行环境不支持背景模糊
- **THEN** 所有内容 MUST 使用不透明或近不透明背景保持同等信息层级与可读性

#### Scenario: 密集活动与文档内容
- **WHEN** 用户浏览长活动列表或 Markdown 文档
- **THEN** 内容区域 MUST NOT 因多层玻璃叠加而降低文本清晰度

### Requirement: 动效遵循统一时长和缓动
界面 MUST 使用统一的短时动效令牌：按压反馈为 100 至 160 毫秒，小型浮层与选择反馈为 125 至 220 毫秒，对话框不超过 300 毫秒；进入与退出 MUST 优先产生即时响应且不得使用迟缓的 ease-in 开始。

#### Scenario: 组件采用默认动效
- **WHEN** 新增组件需要进入、退出或状态变化动画
- **THEN** 组件 MUST 使用共享动效令牌而不是引入任意时长与缓动

#### Scenario: 元素退出
- **WHEN** 菜单、提示或临时内容退出
- **THEN** 退出 MUST 不慢于其进入且不得让界面感觉等待动画结束

### Requirement: 动效不得损害渲染性能
预定的界面过渡 MUST 优先使用可中断的 CSS 过渡，并主要改变 `transform` 与 `opacity`；在正常项目规模和实时更新期间 MUST 避免明显掉帧、布局抖动与持续合成开销。

#### Scenario: 主进程正在扫描项目
- **WHEN** 后台扫描与渲染列表更新同时发生
- **THEN** 当前标签、菜单或对话框过渡 MUST 保持连贯且不依赖主线程逐帧计算

#### Scenario: 进度条更新
- **WHEN** 进度比例频繁变化
- **THEN** 视觉变化 MUST 使用不改变布局轨道尺寸的实现

#### Scenario: 动画结束
- **WHEN** 一次短时过渡完成
- **THEN** 系统 MUST NOT 为静止元素长期保留不必要的动画计时器或循环任务

### Requirement: 尊重减少动态效果和透明度偏好
系统 MUST 响应操作系统的减少动态效果偏好，移除非必要位移与缩放但保留帮助理解的即时透明度或颜色反馈；在减少透明度偏好可用时 MUST 将玻璃表面替换为高对比实色。

#### Scenario: 用户启用减少动态效果
- **WHEN** `prefers-reduced-motion` 为 `reduce`
- **THEN** 菜单、对话框、列表和标签切换 MUST 不产生空间位移或缩放
- **THEN** 所有操作 MUST 保持即时且状态变化仍可通过颜色、边框或短促淡入识别

#### Scenario: 用户启用减少透明度
- **WHEN** 环境报告减少透明度偏好
- **THEN** 导航、工具栏和浮层 MUST 使用足够不透明的表面

### Requirement: 动效状态保持无障碍
动效前后均 MUST 保持语义角色、可见焦点、键盘顺序和屏幕阅读器通知正确；颜色或运动不得成为表达选中、加载、成功或错误状态的唯一方式。

#### Scenario: 键盘浏览版本控件
- **WHEN** 用户仅使用键盘打开版本菜单、切换模式并关闭菜单
- **THEN** 焦点顺序、可见焦点环、方向键与 Escape 行为 MUST 正确

#### Scenario: 保存版本成功或失败
- **WHEN** 保存操作完成或出现错误
- **THEN** 系统 MUST 通过可感知文本和适当的实时区域报告结果
- **THEN** 结果 MUST NOT 仅依赖一次动画表达

### Requirement: 不同窗口尺寸下布局稳定
工作区 MUST 在支持的桌面最小窗口和常用宽屏尺寸下保持控件、文字和浮层互不遮挡；版本标签、长 Change 名称和中文提示 MUST 换行或截断并提供完整可访问名称。

#### Scenario: 最小支持窗口
- **WHEN** 窗口处于应用声明的最小尺寸
- **THEN** 三栏布局和版本控件 MUST 保持可操作且不得出现水平内容覆盖

#### Scenario: 极长版本标签
- **WHEN** 当前标签接近 120 个字符
- **THEN** 导航与标题区 MUST 限制其视觉宽度并允许用户获取完整标签
- **THEN** 标签变化 MUST NOT 推动相邻命令离开可视区域
