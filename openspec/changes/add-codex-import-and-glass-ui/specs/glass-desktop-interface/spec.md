## Purpose

为 OpenSpec 桌面工作区建立适合高频个人开发管理的视觉与交互体系，以 Vercel 式紧凑组件和清晰信息层级为基础，并以克制的 iOS 玻璃材质增强桌面层次感。

## ADDED Requirements

### Requirement: 统一的高密度组件语言

系统 SHALL 使用一致的设计令牌呈现按钮、图标按钮、菜单、输入框、分段控件、状态徽标、进度条、列表行和弹窗，并保持黑白高对比、细边框、紧凑间距和不超过 8 像素的常规圆角。

#### Scenario: 浏览主工作区

- **WHEN** 用户进入包含多个项目和 Change 的工作区
- **THEN** 导航、列表、详情与工具栏呈现一致的尺寸、边界、字重和交互反馈，信息可快速扫描

#### Scenario: 使用熟悉的工具命令

- **WHEN** 某个命令存在通用图标表达
- **THEN** 系统使用 Lucide 图标按钮并提供可访问名称或悬停提示，而不是仅使用带文字的装饰性胶囊按钮

### Requirement: 克制且可降级的玻璃层级

系统 SHALL 仅在应用框架、粘性工具栏、菜单和模态浮层等需要层级区分的位置使用半透明背景、背景模糊、细高光与轻阴影，内容阅读区域保持稳定清晰。

#### Scenario: 系统支持背景模糊

- **WHEN** 运行环境支持 `backdrop-filter`
- **THEN** 指定浮层呈现可辨识的玻璃材质，同时正文、路径和状态文字维持足够对比度

#### Scenario: 系统不支持背景模糊

- **WHEN** 运行环境不支持背景模糊或透明效果被系统关闭
- **THEN** 界面使用不透明实色和边框降级，功能与内容层级不丢失

#### Scenario: 页面处于高信息密度状态

- **WHEN** 工作区同时展示长项目名、多个状态和 Markdown 内容
- **THEN** 系统不使用会干扰阅读的装饰光球、强渐变、过度阴影或大面积透明正文背景

### Requirement: 稳定的桌面工作区布局

系统 SHALL 保留项目、Change 与详情的三栏主流程，并在窗口尺寸变化时维持可操作的导航、稳定的控件尺寸以及不重叠的内容。

#### Scenario: 标准桌面窗口

- **WHEN** 窗口宽度足以容纳三栏工作区
- **THEN** 项目栏、Change 列表和详情面板同时可见，调整内容不会导致工具栏或列表行位移

#### Scenario: 窗口接近最小宽度

- **WHEN** 窗口缩小至应用支持的最小尺寸
- **THEN** 关键命令仍可见，长文本换行或省略，任何标签、按钮、弹窗和正文互不遮挡

#### Scenario: 内容包含超长单词或路径

- **WHEN** 项目名、Change 名称或文件路径超过所在区域宽度
- **THEN** 系统以换行、截断和完整值提示处理，不撑破布局或覆盖相邻控件

### Requirement: 完整的交互状态

系统 MUST 为异步操作和可交互组件提供明确的默认、悬停、按下、焦点、选中、禁用、加载、空、成功和错误状态，且状态变化不应造成布局跳动。

#### Scenario: 导入候选正在加载

- **WHEN** 从 Codex 获取项目候选尚未完成
- **THEN** 导入界面显示尺寸稳定的加载状态，并阻止重复提交

#### Scenario: 命令执行失败

- **WHEN** 添加、刷新或导入命令失败
- **THEN** 相关界面就地显示可读的中文错误反馈，并允许用户重试或关闭

#### Scenario: 使用键盘操作

- **WHEN** 用户通过 Tab、Shift+Tab、Enter、Space 或 Escape 导航和操作
- **THEN** 焦点顺序、焦点可见性、按钮触发和模态关闭符合控件语义

### Requirement: 无障碍与动效偏好

系统 SHALL 为文字和交互控件维持 WCAG 2.2 AA 级别的可辨识度，并尊重用户的减少动态效果偏好。

#### Scenario: 键盘焦点落在控件上

- **WHEN** 任一交互控件获得键盘焦点
- **THEN** 系统显示不依赖颜色单独传达的清晰焦点环，且焦点不被容器裁切

#### Scenario: 用户偏好减少动态效果

- **WHEN** 操作系统启用 `prefers-reduced-motion: reduce`
- **THEN** 系统取消非必要的位移、缩放和模糊过渡，同时保留即时状态反馈

#### Scenario: 状态使用颜色编码

- **WHEN** 监控、就绪或错误状态通过颜色区分
- **THEN** 系统同时提供文字、图标或形状信息，用户无需仅凭颜色判断状态
